# 실제로 걸린 함정 (사례 강의 제작 중 실측)

## 영상
1. **Playwright recordVideo 는 뷰포트보다 큰 size 를 주면 확대하지 않고 회색 여백을 붙인다.** 1536×864 뷰포트를 1920×1080 으로 녹화하면 왼쪽 위에만 그려진다. → `size` 를 뷰포트와 같게 녹화하고 ffmpeg `scale` 로 키운다. 이미 찍었다면 `crop=1536:864:0:0,scale=1920:1080` 로 복구.
2. **640px 축소 프레임으로는 1번을 못 본다.** 검수는 원본 해상도 한 장 + 모서리 픽셀 값 확인.
3. 데모 스크립트 실행에 '통과' 배지를 붙이면 틀린 출력도 통과처럼 보인다 → `demo: true`.
4. 함수 단위 수정인데 파일 전체 diff 를 보여 주면 관계없는 줄이 섞이고 긴 줄이 잘린다 → 함수 블록만, 줄 바꿈 허용, 줄이 많으면 글자 크기 자동 축소.
5. `--only` 부분 렌더에서 작업 사본을 초기화하지 않으면 앞 수정이 남아 '시작본 실행'이 통과한다(렌더러가 기대 불일치로 멈춰서 발견) → 항상 초기화하고 앞 수정은 순서대로 재적용.
6. gpt-6-astra 다듬기는 초안을 5~10% 늘린다. 길이 목표가 있으면 `polish_ratio` 로 줄인다.
7. 이미 끝난 센서 결측이 60초 창에 남아 **실제 이상을 센서 오류로 판단**(영상 리허설에서 발견) → 현재 상태는 최근 구간으로 판단하고 앞선 문제는 별도 플래그.
8. FAST 리허설(대기만 줄임)을 먼저 돌려라 — 타이밍 의존 버그가 FAST 에서 먼저 드러났다.

## 교재·그림
9. **그림 제목의 인과 주장이 틀렸다**: "지속 조건이 오탐을 4→1 로 줄였다" → 격자 재평가 결과 허용 한계 효과였고 지속은 지연만 늘렸다. 두 매개변수를 동시에 바꾼 비교는 쓰지 않는다. 작성자(서브에이전트)가 재실행으로 잡았다.
10. 절 번호를 Skill 문서에 박으면 LLM 이 검색되지 않은 절을 인용 → 근거 검증이 막는다(안전장치는 정상). Skill 에는 "검색 결과에 있는 절만 인용".
11. 측정 없이 정한 급등 기준(유량 6 L/min)이 정상 펌프 기동(최대 10.9)을 급등으로 판정 → 기준은 측정한 정상 최대 변화 위로.
12. 중앙값 대비 급등 판정은 빠른 실제 상승을 전부 막았다 → 직전 유효값 대비 1초 점프 + 연속이면 수준 변화.
13. 관계 근거가 다른 설비 전용 문서를 가리키는 시드 오류 → 근거는 그 설비에 적용되는 문서여야 한다.

## 시스템·플랫폼
14. 실패한 인스턴스가 남긴 **열린 사건**이 "설비·유형당 열린 사건 하나" 규칙에 걸려 새 감지를 막았다 → 초기화 시 이전 실행의 열린 사건을 별도 상태로 닫는다(회복으로 기록하지 않는다).
15. OpenAI 함수 스키마는 타입 없는 `list[dict]` 인자를 거부한다 → 명시적 모델 타입.
16. 다른 인스턴스가 처리된 사건 상태를 되돌릴 수 있었다 → 상태 전이 전 현재 상태 확인(409).
17. 발행 후 매핑을 고치면 발행하지 않은 매핑으로 조회됐다 → 발행 스냅샷으로 조회.
18. 서버 재시작(모드 전환)이 병렬 작업의 읽기 테스트를 깨뜨릴 수 있다 → 모드별 제작 대기열.
19. 기존 서비스 포트 충돌(8900 이 다른 컨테이너) → 시작 전 `lsof -iTCP -sTCP:LISTEN`.
20. 공유 테스트가 TRUNCATE → 테스트 전용 DB.

## 작업 방식
21. 서브에이전트 보고의 "시스템과 다른 점"은 가장 값진 출력이다. 문서로 우회하지 말고 시스템을 고친 뒤 재동기화를 요청한다.
22. 대기 스크립트가 로그 속 pytest 의 `FAILED` 문자열에 반응해 조기 종료할 수 있다 → 완료 표식은 `== <ID> DONE|== <ID> FAILED` 처럼 고유하게.
23. 샌드박스 셸에서는 `ps` 로 백그라운드 프로세스가 안 보일 수 있다 → 로그 수정 시각으로 생존 확인.
24. 푸시 직전 저장소가 이미 있고 다른 세션이 계속 푸시 중이었다 → 이름 변경/새 저장소를 사용자에게 묻는다.
