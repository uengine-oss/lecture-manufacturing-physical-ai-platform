저장소를 나누는 기준 — DB 는 PostgreSQL 과 Neo4j 두 개

원시 파일은 파일 저장소, 수치 관측과 실행 이력은 PostgreSQL, 설비 관계와 SOP 검색은 Neo4j. 처음부터 시계열 전체를 그래프 노드로 만들지 않는다.

Neo4j · 관계와 문서

(:Asset:Resource)asset_id name cooling line
-[:HAS_SENSOR]→ (:Sensor:Measure)sensor_id code quantity unit hz aliases
(:SOP)-[:APPLIES_TO]→(:Asset)doc_id version effective_date status · -[:HAS_SECTION]→(:SOPSection {text, embedding}) · -[:ALLOWS]→(:Action)
(:Event 참조)-[:ON_ASSET]→ · -[:CITES]→(:SOPSection)event_id status — 수치 상세는 PostgreSQL 에서
결합 기준 asset_id 로 그래프 맥락과 시계열 결과를 잇고, event_id 로 감지·근거·승인·조치·재측정을 잇는다. 플랫폼에서는 수치를 원천 DB 에 두고(가상 연결) 문서 지식만 그래프에 둔다.
