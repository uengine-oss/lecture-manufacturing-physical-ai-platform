# SOP-ESC-001 미개선 이관 (교육용)

## 1. 적용 설비
HYD-01, HYD-02의 냉각 이상 사건 중 조치 후에도 회복하지 않은 사건에 적용한다.

## 2. 발동 조건
재점검 결과가 미개선이거나, 조치 명령이 실패했거나, 허용 조치를 이미 한 번 실행한 사건에서 이상이 이어지면 발동한다.

## 3. 확인할 관측
조치 전후 온도 평균, 조치 명령 결과, 재측정 구간을 사건 기록에 첨부한다.

## 4. 허용 조치
ESCALATE: 정비 책임자에게 사건을 넘긴다. 같은 조치를 반복 실행하지 않는다.

## 5. 승인 주체
정비 책임자가 이관을 접수한다.

## 6. 재점검 기준
정비 완료 후 새 사건으로 다시 감시한다.
