# SOP-COOL-002 냉각 이상 확인 — HYD-02 공랭식 (교육용)

## 1. 적용 설비
HYD-02 공랭식 유압설비에만 적용한다. HYD-01에는 적용하지 않는다.

## 2. 발동 조건
유효한 온도 관측이 58°C를 넘는 상태가 15초 이상 이어지면 발동한다.

## 3. 확인할 관측
팬 회전수와 외기 온도를 확인한다.

## 4. 허용 조치
허용 조치는 냉각 팬 증속(FAN_BOOST)으로 팬 속도 배수를 1.3으로 올린다. 허용 값 범위는 1.0 이상 1.5 이하다. 부하 감소는 이 절차의 허용 조치가 아니다.

## 5. 승인 주체
2호기 담당자가 승인한다.

## 6. 재점검 기준
증속 후 60초 안에 55°C 이하로 내려오는지 확인한다.
