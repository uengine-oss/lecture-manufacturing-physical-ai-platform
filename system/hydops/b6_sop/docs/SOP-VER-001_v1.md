# SOP-VER-001 조치 후 재점검 (교육용)

## 1. 적용 설비
HYD-01, HYD-02에서 승인 조치를 실행한 모든 사건에 적용한다.

## 2. 발동 조건
조치 명령이 성공으로 기록되면 30초 대기 후 발동한다. 조치 이전의 관측은 재측정에 쓰지 않는다.

## 3. 확인할 관측
대기 후 60초 창의 유효 온도 관측을 본다. 55°C 이하가 10초 이상 연속으로 유지되면 회복이다. 창 안의 유효 관측 비율이 70% 미만이면 데이터 부족으로 판정을 보류한다.

## 4. 허용 조치
재점검은 관측만 하며 새 조치를 하지 않는다.

## 5. 승인 주체
판정 결과는 설비 담당자가 사건 화면에서 확인한다.

## 6. 재점검 기준
회복이면 사건을 종결한다. 미개선이면 SOP-ESC-001로 이관한다. 데이터 부족이면 센서 점검 후 다시 재측정한다.
