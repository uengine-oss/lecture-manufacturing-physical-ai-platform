# SOP-COOL-001 냉각 이상 확인 (교육용, 폐기된 1판)

## 1. 적용 설비
HYD-01 유압설비 냉각 계통에 적용한다.

## 2. 발동 조건
온도가 65°C를 넘으면 발동한다. (2판에서 60°C 10초 지속 조건으로 개정되었다.)

## 3. 확인할 관측
온도 값만 확인한다.

## 4. 허용 조치
부하를 0.7로 낮춘다.

## 5. 승인 주체
현장 작업자가 판단한다.

## 6. 재점검 기준
별도 기준이 없다.
