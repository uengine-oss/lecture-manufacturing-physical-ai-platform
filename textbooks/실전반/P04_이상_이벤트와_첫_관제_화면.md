## 이번 회차에서 할 일

1~3회차에서 관측이 PostgreSQL 에 쌓이고(B1~B3), 설비·센서·SOP 관계를 그래프로 조회할 수 있게 되었다(B4). 오늘은 그 관측을 읽어 **사건(event)** 을 만드는 B5 와, 그 사건을 사람이 보는 B9 관제 화면을 잇는다. 수치 감지는 규칙과 이동 통계로 한다. UCI 재생 데이터에서는 "같은 위상의 정상 사이클과 비교한 잔차"를, 시뮬레이터 스트림에서는 "유효 온도 60°C 초과 10초 연속"을 쓴다. 두 규칙 모두 **지속 조건**과 **중복 억제**가 없으면 단발 오류가 사건이 되거나 같은 이상이 사건 수십 건으로 쪼개진다. 회차가 끝나면 고정된 시험 구간에서 오탐·누락·지연을 숫자로 말하고, 코드·데이터·설정을 학기말 체크포인트로 남긴다. 이것이 1학기(M1·M2)의 마지막 시간이다.

### 학습 목표
- 정상 위상 기준(`PhaseBaseline`)과 이동평균 잔차로 한 사이클의 이상 여부와 감지 지연을 계산한다.
- 지속 카운터가 `MISSING`·`SPIKE` 단발에는 유지되고 유효 저온·`GAP` 에서만 초기화되도록 감지 함수를 고치고, 시스템 `ThresholdDetector` 와 같은 감지 구간을 내는지 검증한다.
- "설비·유형당 열린 사건 하나" 규칙을 구현하고, DB 부분 유일 인덱스와 관제 API 에서 같은 규칙을 확인한다.
- 고정 시험 구간(시드 2026, 시험 180 사이클)에서 지속 조건만 바꿔 평가하고, 오탐을 줄인 것이 지속 조건인지 임계값인지 구분해 설명한다.

## 2. 핵심 개념

![하나의 사건이 통과하는 경로](../../materials/diagrams/D02_event_path.png)

오늘 다루는 것은 그림 윗줄 B5 탐지 → event 생성, 그리고 맨 아래 B9 관제 띠다. B7·B8 은 다음 학기에 붙는다. 사건은 `event_id` 를 받는 순간부터 근거·승인·조치·재측정 기록을 모두 같은 키로 모은다. 그래서 **사건을 몇 개 만들었는가**가 뒤 블록 전체의 부담을 정한다.

### 2.1 두 가지 감지 규칙

| 데이터 | 함수 | 규칙 | 쓰는 곳 |
|---|---|---|---|
| UCI 재생 (사이클 60초) | `detector.detect_cycle_phase` | 잔차 = 5초 이동평균 − 같은 위상 정상 평균. 잔차 > max(4σ, 3°C) 가 10초 연속이면 이상 | 오프라인 평가 (`evaluate.py`) |
| 시뮬레이터 스트림 | `detector.ThresholdDetector.feed` | 품질 OK 인 온도 > 60°C 가 10번 연속이면 `COOLING_ANOMALY`, `GAP`·`STUCK` 이면 `SENSOR_FAULT` | 관제 서버 런타임 (`runtime.py`) |

두 규칙 모두 **교육용 가정값**이다. UCI 설비의 운전 기준이 아니다. 그리고 둘 다 규칙 기반 감지다. 사전학습 시계열 모델(zero-shot)은 활동 4 의 선택 비교로만 쓴다.

### 2.2 정상 위상 기준

UCI 사이클 안에서 온도는 운전 위상에 따라 조금씩 움직인다. 같은 경과 초(`elapsed_s`)끼리 비교하면 위상 차이를 이상으로 착각하지 않는다.

![정상 위상 기준과 이동평균 잔차](../../materials/figures/F04_phase_baseline_residual.png)

왼쪽은 정상 기준 244 사이클의 평균(파랑)과 두 시험 사이클이다. 오른쪽은 잔차다. #760(냉각기 20%)은 잔차가 약 12°C 로 한계선(빨간 점선)을 줄곧 넘어 10초째에 감지된다(지연 9초). #1467(냉각기 100%, 정상 라벨)도 잔차가 약 5°C 로 한계를 넘는다. 이 사이클이 활동 4 에서 만나는 오탐 1건이다.

> 주의: `profile.cooler_pct` 는 **설비 상태 라벨**이다. 제품 불량이 아니다. 그리고 평가에만 쓰고 탐지 입력에 넣지 않는다.

### 2.3 지속 조건과 중복 억제는 다른 문제를 막는다

| 장치 | 막는 것 | 코드 위치 |
|---|---|---|
| 지속 조건 | 단발 급등·짧은 흔들림이 사건이 되는 것 | `ThresholdDetector.feed` 의 `above_run`, `detect_cycle_phase` 의 `sustain_s` |
| 품질 플래그 구분 | 센서 오류 값이 설비 이상으로 세어지는 것 | `flag == OK and value is not None` 조건 |
| 중복 억제 | 이미 열린 이상에 사건이 또 생기는 것 | `store.create_event` 의 `open_event` + DB 부분 유일 인덱스 `ux_event_open` |

## 3. 활동 1 — 정상 위상 기준과 이동 통계 적용 · 50분

### 목표
고정 분할의 기준 사이클로 `PhaseBaseline` 을 만들고, 두 시험 사이클의 잔차·감지 시점을 직접 계산한다. 한계값을 정하는 항이 실제로는 무엇인지 확인한다.

### 따라 하기

1. 고정 분할을 두 번 불러 같은지 확인하고, 기준을 적합한다.

```bash
PYTHONPATH=. .venv/bin/python -c "
from hydops.b5_detect import evaluate as E
from hydops.b5_detect.detector import PhaseBaseline, detect_cycle_phase
import numpy as np
ds, base, test = E.fixed_split(); _, _, test2 = E.fixed_split()
print(len(base), len(test), test == test2, test[:5])
temps = ds.sensors['TS1']['mean']; bl = PhaseBaseline.fit(temps, base)
lim = np.maximum(4*np.asarray(bl.std), 3.0)
print('mean', round(min(bl.mean),2), round(max(bl.mean),2), 'std', round(min(bl.std),3), round(max(bl.std),3), 'limit', lim.min(), lim.max())
for cid in (760, 1467):
    r = detect_cycle_phase(temps[cid], bl)
    print(cid, int(ds.profile.loc[cid,'cooler_pct']), r['is_anomaly'], r['first_alarm_s'], round(r['max_residual'],2))
"
```

2. 출력의 `limit` 줄을 먼저 읽는다.

### 확인 포인트

```
244 180 True [21, 30, 34, 63, 64]
mean 35.69 36.17 std 0.301 0.323 limit 3.0 3.0
760 20 True 9 12.17
1467 100 True 9 5.46
```

- 기준 244 사이클, 시험 180 사이클이며 두 번 불러도 시험 사이클이 같다(`True`).
- 위상별 표준편차가 0.30~0.32°C 라서 4σ 는 약 1.3°C 다. 한계 `max(4σ, 3°C)` 는 **모든 위상에서 3.0°C**, 즉 `min_delta_c` 가 한계를 정한다. `k_sigma` 를 3·4·5 로 바꿔도 결과가 같은 이유다.
- `first_alarm_s` 9 는 "10초 연속" 조건의 10번째 초(0부터 셈)다.

### 흔한 실수
- 기준 사이클에 시험 사이클을 섞는다. `fixed_split` 은 정상·안정 사이클 절반으로 기준을 만들고, **나머지에서만** 상태별 60개를 뽑는다.
- 잔차 계산에 이동평균을 빼먹는다(`smooth_s=1`). 1초 흔들림이 그대로 한계와 비교된다.
- 시험 결과를 보고 `min_delta_c` 를 고친 뒤 같은 시험 구간으로 다시 보고한다. 그러면 시험 구간이 기준 구간이 된다.

### 흔한 실수
- `raw_value` 로 센다. 정상 운전(냉각 1.0) 중 급등 한 번(원시값 74.826, `SPIKE`)만으로 지속 1초 시작본은 신호 1건, 정답본은 0건이다.
- `MISSING` 에서도 초기화한다. 짧은 결측이 잦은 센서에서는 이상이 계속 늦게, 또는 영영 감지되지 않는다.
- `GAP` 에서도 카운터를 유지한다. 5초 이상 모르는 구간을 "계속 높았다"고 가정하는 셈이다.
- 중복 억제를 감지 함수 안의 "한 번 울렸으면 끝" 플래그로 구현한다. 사건이 종결된 뒤 재발해도 다시 울리지 않는다. 억제 기준은 **열린 사건의 상태**여야 한다.

UCI 시험 구간에서 오탐 4건 → 1건은 **최소 차이 1°C → 3°C** 가 만든 결과다. UCI 사이클은 한 사이클 안에서 냉각기 상태가 바뀌지 않아, 한계를 넘는 사이클은 대부분 60초 내내 넘는다. 그래서 지속 조건은 여기서 지연만 늘린다. 남은 오탐 #1467 은 `stable_flag=1`(안정 상태 미도달) 정상 사이클이다. 지속 조건의 효과는 활동 2 의 스트림(단발 급등, 60°C 경계)에서 드러난다. **어느 데이터에서 무엇을 막는지**를 나눠 말하는 것이 오늘의 완료 확인이다.
