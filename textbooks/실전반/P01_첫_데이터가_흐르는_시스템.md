## 이번 회차에서 할 일

이번 학기에 만드는 시스템은 유압설비의 냉각 이상을 발견하고, 설비 관계와 SOP 를 확인한 뒤, 사람이 승인한 조치를 실행하고 새 관측으로 회복을 다시 측정한다. 오늘은 그 맨 앞, Data Sources 계층의 B1(데이터)·B2(품질 검사)·B3(PostgreSQL)을 잇는다. UCI 유압설비 데이터의 세 센서 파일은 샘플링 주기와 단위가 모두 다르다. 이것을 하나의 공통 관측 레코드로 매핑하고, 제공 품질 검사기와 적재 함수로 PostgreSQL 에 넣은 뒤, 최근 60초를 조회해 그 값이 어느 원본 사이클에서 왔는지 추적한다. 회차가 끝나면 "이 값은 HYD-01 의 TS1, 단위 °C, UCI 원본 사이클 102 의 12초째, 합성 아님"이라고 DB 조회 결과로 말할 수 있어야 한다.

### 학습 목표
- 완성 시스템 화면에서 B1~B9 블록과 네 계층(Data Sources / Ontology / Agents / Orchestration)의 위치를 짚는다.
- 1 Hz·10 Hz·100 Hz 센서를 1초 mean·min·max·n 으로 축약하는 함수를 고치고, 강사 제공 축약본과 값이 같은지 검증한다.
- 관측 레코드에 설비 ID·단위·원본 사이클·위상(elapsed_s)·원본/합성 구분을 넣어 PostgreSQL 에 적재한다.
- run_id 조건이 있는 최근 60초 조회와 없는 조회의 결과 차이를 설명한다.

## 2. 핵심 개념

![완성 시스템 아키텍처](../../materials/diagrams/D01_architecture.png)

오늘 다루는 것은 그림 맨 윗줄 Data Sources 의 B1 → B2 → B3 이다. 뒤 회차의 모든 블록은 이 줄이 만든 관측 레코드를 읽는다. 공통 연결 키는 그림 아래의 `asset_id` · `event_id` · `run_id` 인데, 오늘은 `asset_id` 와 `run_id` 를 처음 쓴다.

### 2.1 공통 관측 레코드

`hydops/b1_data/uci.py` 의 `cycle_observations` 가 만드는 레코드가 이 시스템의 표준 형식이다.

```python
# lecture/system/hydops/b1_data/uci.py (발췌)
rows.append(
    {
        "asset_id": asset_id,
        "sensor_id": sid,
        "ts": replay_start + timedelta(seconds=s),
        "elapsed_s": s,
        "origin_cycle_id": int(cycle_id),
        "raw_value": mean,
        "unit": meta["unit"],
        "agg": None
        if meta["hz"] == 1
        else {
            "min": round(float(stats["min"][cycle_id, s]), 4),
            "max": round(float(stats["max"][cycle_id, s]), 4),
            "n": int(stats["n"][cycle_id, s]),
            "source_hz": meta["hz"],
        },
        "is_synthetic": False,
    }
)
```

| 필드 | 의미 | 주의 |
|---|---|---|
| `ts` | 재생 시각 | 실제 수집 시각이 아니다 |
| `elapsed_s` | 사이클 안의 경과 초(위상) | 0~59 |
| `origin_cycle_id` | UCI 원본 사이클 번호 | 시뮬레이터(합성)는 NULL |
| `raw_value` | 1초 평균(원시 값) | 결측이면 NULL |
| `unit` | °C / bar / L/min | 센서마다 다르다 |
| `agg` | 1초 축약 통계 min·max·n·source_hz | 1 Hz 센서는 없음 |
| `is_synthetic` | 원본/합성 구분 | UCI 재생은 false |

> **주의** — 재생 시각을 실제 수집 시각이라 부르지 않는다. UCI 데이터에는 실측 날짜가 없고, 우리가 정한 재생 시작 시각에 사이클을 이어 붙였을 뿐이다. 그래서 원본을 되찾을 수 있도록 `origin_cycle_id` 와 `elapsed_s` 를 따로 둔다.

사이클 #100 의 세 센서다. TS1 은 이미 1초 간격이라 그대로 쓴다. PS1 은 1초에 100개 샘플이 있어 1초 안에서도 크게 흔들리므로 평균만 남기면 순간 변동이 사라진다. 그래서 최솟값·최댓값 띠를 함께 남긴다. FS1 은 10개 샘플의 평균을 쓰고 원본 샘플 수 n=10 을 기록한다. 첫 샘플만 골라 쓰는 **솎아내기**는 축약이 아니다 — 활동 2 에서 그 차이를 숫자로 확인한다.

### 2.3 저장소 나누기

![저장소 분리](../../materials/diagrams/D07_storage.png)

원시 파일은 파일 저장소, 수치 관측과 실행 이력은 PostgreSQL, 설비 관계와 SOP 는 Neo4j 에 둔다. 오늘은 가운데 `observation` 과 `run` 만 쓴다. `run.source` 는 `'uci_replay'` 또는 `'simulator'` 만 허용하는 CHECK 제약이 걸려 있다.

```sql
-- lecture/system/sql/01_schema.sql (발췌)
CREATE TABLE IF NOT EXISTS run (
    run_id        TEXT PRIMARY KEY,
    source        TEXT NOT NULL CHECK (source IN ('uci_replay', 'simulator')),  -- 원본/합성 구분
    ...
);
CREATE TABLE IF NOT EXISTS observation (
    ...
    ts              TIMESTAMPTZ NOT NULL,      -- replay_ts (재생 시각, 실제 수집 시각 아님)
    elapsed_s       INTEGER,                   -- 사이클 내 경과 초 (위상)
    origin_cycle_id INTEGER,                   -- UCI 원본 사이클 번호 (합성은 NULL)
    raw_value       DOUBLE PRECISION,          -- 원시 값 (결측이면 NULL)
    value           DOUBLE PRECISION,          -- 정제 값 (품질 불량이면 NULL)
    unit            TEXT NOT NULL,
    quality_flag    TEXT NOT NULL DEFAULT 'OK',
    agg             JSONB,                     -- 1초 축약 통계 (min/max/n)
    is_synthetic    BOOLEAN NOT NULL DEFAULT false
);
```

   ```python
   # lecture/labs/practical/S01/mapping.py (시작본 발췌)
   def reduce_to_seconds(samples: np.ndarray, hz: int) -> list[dict]:
       """60초 × hz 샘플을 1초 단위 mean/min/max/n 60개로 축약한다."""
       if len(samples) != CYCLE_S * hz:
           raise ValueError(f"샘플 수 {len(samples)} != {CYCLE_S} x {hz}")
       shaped = samples.reshape(CYCLE_S, hz)
       # TODO(학생): 지금은 1초 구간의 첫 샘플만 골라 쓴다(솎아내기). ...
   ```

## 5. 활동 3 — 제공 적재 함수를 PostgreSQL에 연결 · 50분

### 목표
매핑한 레코드를 제공 품질 검사기(B2)와 제공 적재 함수(B3)에 연결해 `LAB-` run 으로 적재한다.

### 따라 하기
1. 제공 적재 함수를 읽는다. COPY 로 한 번에 넣고, 레코드에 `value`·`quality_flag` 가 없으면 NULL·`'OK'` 로 들어간다. 그래서 품질 검사를 먼저 거쳐야 한다.

   ```python
   # lecture/system/hydops/b3_tsdb/store.py (발췌)
   def insert_observations(run_id: str, rows: list[dict]) -> int:
   ```

1. 제공 조회 함수를 읽는다. 기준 시각은 **해당 설비의 마지막 관측 시각**이고, run_id 를 주면 그 run 안에서만 찾는다.

   ```python
   # lecture/system/hydops/b3_tsdb/store.py (발췌)
   def recent_window(asset_id: str, seconds: int = 60, sensor_id: str | None = None, run_id: str | None = None, until: datetime | None = None) -> list[dict]:
       """설비별 최근 구간 SELECT. 기준 시각은 해당 설비의 마지막 관측 시각(재생 시각)이다."""
       with connect() as c:
           if until is None:
               q = "SELECT max(ts) AS t FROM observation WHERE asset_id=%s" + (" AND run_id=%s" if run_id else "")
               until = c.execute(q, (asset_id, run_id) if run_id else (asset_id,)).fetchone()["t"]
   ```
